# IT303 Nuxt Portfolio Starter

## Requirements
- Node.js (LTS recommended)
- npm

## Run locally
1. Extract this folder.
2. Open the folder in VS Code.
3. In the terminal, run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed by Nuxt (usually http://localhost:3000).

## Personalize
- Replace `YOUR NAME` / `Your Name` in `components/NavbarHeader.vue` and `pages/index.vue`.
- Replace the placeholder email in `pages/index.vue`.
- Update project cards and skills in `pages/index.vue`.
- Add your own project URLs.

## Component structure
- `layouts/default.vue`: overall page layout
- `components/NavbarHeader.vue`: navigation header
- `components/SiteFooter.vue`: footer
- `components/ProjectCard.vue`: reusable project card
- `pages/index.vue`: home page sections
- `assets/css/main.css`: styles

This is a starter template; customize the content to meet the course rubric and your instructor's requirements.
